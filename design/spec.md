# FDE 备考界面规格

三列布局：左侧导航 192px，主答题区自适应，右侧考纲栏 270px。使用白色面板、浅灰背景 #f3f6fa、深蓝正文 #122341、蓝色主按钮 #0865ef 和边框 #dce4ef；圆角 8px。

题干 22px，正文 16px、行高 1.8，标签 13px。答题选项、正确/错误/禁用状态和解析均以 HTML/CSS 表达，不依赖图片、远程字体或模型 API。

导航包括章节学习、间隔复习、错题本、收藏、模拟考试、学习进度、数据备份和题库版本。主要路径为筛选或检索题目、选择、提交、查看解析和来源、下一题或收藏。考试交卷前隐藏解析。

宽度低于 760px 时导航改为横向按钮，右侧考纲移至主区下方，筛选器垂直排列。键盘操作支持 A–E 选项。题目数量、来源版本及保存状态以实际数据为准。

公开版本的题库说明展示原创题分组、复核统计与练习入口，不包含私人模拟考试证据。
