## 证据方法与边界

对照 [官方考试指南](https://cloud.tencent.com/document/product/658/137832)「知识点占比与考核重点」L62–64，版本 2026-09-10：M1 为基础概念和原理，M2 为定位、模式选择及与知识库/工作流/插件的关系。将具体界面、接口默认参数或订阅条款认定为其他模块/延伸学习，是审计推断，不是官方宣称这些内容绝不考。

JSON 的 sourceEvidence 包含重新读取的官方 URL、具体章节、页内词或工具行号、短事实与页面版本。未把题库原 sources.fact、先前通过记录或 AI 审校数量作为独立证据。检索日期不等于文档更新时间。词汇表此次打开为聚合词条页，没有可确认的独立更新时间，明确记录了这一点。

原 115872「连接器与工具介绍」在本轮通过直接打开、官方站内链接及普通公开 HTTP 均未取得正文。替代 115873、115874、117855、115748 得到的是**搜索工具返回的多段正文摘录**，包含标题、日期和章节；没有声称已读全页。只采用明确可见的 MCP 定义、工具契约、Python 函数及外部系统操作等句子，retrievalScope 已逐条标注。工具单轮、OpenAPI 精确版本及大陆页第三方担保原文未补齐，因此隔离，不借其他产品的接口或 PE 单轮限制推断。

## 事实成立仍需剔出模拟配额的主要原因

- **模块覆盖偏移**：M1-080/081/096/101依赖 TI-ONE 训练任务或数据格式；M1-033为 GetEmbedding 的默认类型；M1-054为工作台摘要栏位，056–058为具体记忆库规则；M1-090/091为 GraphSchema 表示。并非事实都错，而是不能直接充当基础原理的100个独立考点。M2-025按钮入口、030语言实现、050–055节点和运行配置、069/070资源或订阅规则，更适合功能、运维或附录。
- **明显弱干扰**：如 M1-065 把语音任务干扰写成文件大小/向量重排；M1-076 的“万能工具不提供参数”；M1-085 的“文字Token指定镜头”；M2-064 的“无需接入读取任意企业全部数据”。其正确答案虽可证实，排除法难度接近常识。逐题 rationale 和 difficultyConcern 给出了应该换成的邻近技术取舍。
- **多选包装并未增加难度**：M1-068、079、084、085、087，M2-053、062–065等仅删除一个跨层或绝对化错误选项。原“综合”标注没有实质或测量依据。
- **实质重复与主题相近分开处理**：工具契约 M1-029/076 与 M2-056；输出长度 M1-014 与 M3-033；停用记忆 M1-058 与 M3-155；M1-008/043（检索上下文与训练）；M1-040/098（相似分与实际证据）；M2-017/018（Claw不能互切的反向再问）。这些已比较具体认知任务，不只凭相似词。GraphRAG实体、属性、三元组同源属于主题密集，不全部强行标成同题。

## 覆盖缺口与下一步

当前 M1 名义配额包含大量产品字段、图谱术语和调优操作。与官方明确点名的“幻觉”相比，主要是“不编造/不能保证正确”的散落反例，没有充分的幻觉概念、发生条件及证据支持性辨析。大模型基本原理也更多是部署/精调/训练数据字段，缺少平衡的概念机制考查。上述缺口是对当前100题的内容观察，不能据此自行杜撰官方未公开的细粒度考纲。

应先以当前可定位资料冻结真正的基础目标，再替换弱项和重复项；不得只换名词或调选项顺序。新增题仍需另一个审阅者核实。已被标记 learning_only/hold 的当前题不能继续按原1000题总数对外声称“全部独立有效且契合考试”。

本轮只审核 M1/M2 全量及已指定的跨模块重复对；没有重新审核全库所有两两组合。实际考试风格相似度及难度仍无官方样卷、授权真题或人工专家依据。
