# 研究与命题资料

这些文件保留原创命题源码、腾讯官方来源索引、逐题审校记录和修订差异，用于追溯题库内容。文件中的日期、AI 角色名称与哈希是历史证据，不能代表发布日再次联网核验或人工认证。

当前可运行题库、用途分级与版本以 `../data/` 为准。旧批次、早期审校和跨题比较可能引用已修订的原创题目；它们不应作为当前答案依据。

历史构建与报告脚本为实现资料，可能依赖未公开的旧快照或旧验收输出，并会改写当前文件。不要直接运行来重建本版。日常运行只需根目录服务和 `src/`、`data/`；结构验证使用 `scripts/validate_bank.py`，安全发行打包使用 `scripts/package_release.py`。

公开副本排除了个人学习记录、私人模拟考复盘、官方原题及其答案证据、录屏/截图/OCR、旧发行备份、迁移记录和机器运行日志。当前 `round1/source-evidence.json` 仅保留公开课程来源，不含私人证据。

题库是非官方原创模拟题；审校是 AI 的事实与表达检查，无法证明命中率或真实考试难度等值。许可选择范围见根目录 `LICENSING.md`。
